# 码上影院后台

码上影院后台项目

## 项目描述

使用SpringBoot+Springmvc+mybatisplus来实现后端

## 特性

列出项目的主要特性和功能。

- 解决用户线上购票问题
- 后台实现对电影、影院、影厅、排片的管理
- 后台可通过权限管理实现多级管理员

## 安装和使用

开发环境：

- java 1.8
- maven 3.8.2
- mysql  8.0.30
- redis 

### 安装

```shell
$ git clone https://gitee.com/saodi99/cinema-backend.git
```

### 使用

项目结构：

- commons
  - 通用模块
- app
  - 客户端接口
- manager
  - 管理员接口

1. 配置`application.yml`中的redis mysql端口等
2. 参考 SpringBoot 项目的启动方法
3. 启动 redis
