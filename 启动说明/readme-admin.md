# 项目名称

码上影院管理员后台

## 项目描述

基于 [参考项目](https://github.com/lin-xin/vue-manage-system) 的二次开发
Vue+Element Plus

## 安装和使用

提供安装和使用项目的指南。

### 安装

在这里列出安装项目所需的步骤。

```shell
$ git clone https://gitee.com/saodi99/admin-front-end.git

$ npm install
```

### 使用

在这里提供如何使用项目的说明。

```shell
$ npm run serve
```
访问 http://localhost:8081
